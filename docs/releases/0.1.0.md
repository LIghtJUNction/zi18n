# zi18n 0.1.0

zi18n 0.1.0 is available on crates.io. It provides borrowed localization catalogs, explicit fallback, and named template rendering for Rust applications. The default core requires no allocator and has zero runtime dependencies. The minimum Rust version is 1.85.0. [Crates.io](https://crates.io/crates/zi18n/0.1.0), [API documentation](https://docs.rs/zi18n/0.1.0/zi18n/)

## Using catalogs

A locale is a language tag chosen by the application. A catalog associates that locale with message keys and their text or plural forms. Define catalogs as static slices or borrow them from application data. The application supplies the requested locale and the fallback order.

Lookup searches for each key in the exact requested locale, its truncated parents, and then the configured fallback catalogs in order. Each configured fallback names an existing catalog, ignoring ASCII case. An empty list uses only the requested hierarchy. The result carries the actual matched locale, and a missing key returns a typed error. Parent truncation follows the singleton rule in RFC 4647 §3.4. [Lookup reference](https://www.rfc-editor.org/rfc/rfc4647.html#section-3.4)

A template inserts display values at named placeholders such as `{count}`. Doubling a brace writes it literally. The formatter validates the template and arguments before writing to the sink, and braces produced by a value remain literal. A sink or display error can leave a partial prefix.

Locale-aware plural selection gives the rules provider the actual matched locale. The built-in cardinal helper covers plain `u64` counts for primary languages `en` and `zh`. English uses `One` for 1 and `Other` otherwise, and Chinese always uses `Other`. Applications can pass an external rule provider to `select_plural_with` for other locales or operands. [CLDR 49 cardinal rules](https://github.com/unicode-org/cldr/blob/96e54b273d2da4ec6fbad350ba19ff23fa24a588/common/supplemental/plurals.xml)
